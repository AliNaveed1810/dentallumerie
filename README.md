# LUMIÈRE Dental Studio

Premium multi-page dental clinic website concept built with Next.js, React, TypeScript and Tailwind CSS.

This is a **fictional clinic portfolio** designed to demonstrate how a high-end private dental practice website can convert visitors into appointment enquiries — with WhatsApp and AI receptionist integration points ready for automation workflows.

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion
- React Hook Form + Zod
- Lucide icons

## Pages

| Route | Purpose |
| --- | --- |
| `/` | Premium homepage |
| `/about` | Clinic story and philosophy |
| `/treatments` | All dental services |
| `/treatments/[slug]` | Individual treatment landing pages |
| `/our-team` | Dentist / team profiles |
| `/contact` | Location, hours and contact |
| `/book-appointment` | Appointment enquiry form |

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Conversion features

- Appointment enquiry form with client + server Zod validation
- Next.js API route at `/api/appointments` (email / automation ready)
- Floating WhatsApp button
- AI receptionist chat placeholder (demo responses)
- Success confirmation screen
- FAQ accordion
- Mobile sticky booking CTA

## Demo notice

All clinic details, testimonials context and team profiles are fictional. The site intentionally avoids collecting medical records or sensitive patient data.
